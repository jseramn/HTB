# HTB

Evidence of my [Hack The Box](https://www.hackthebox.com/) work: machines, challenges, Sherlocks and Academy modules.

## Structure

| Folder | Content |
|---|---|
| `machines/` | One folder per machine: `machines/<name>/README.md` plus screenshots |
| `challenges/` | Challenges by category (web, crypto, pwn, reversing, forensics, misc) |
| `sherlocks/` | Defensive / DFIR investigations |
| `academy/` | Notes from HTB Academy modules |
| `templates/` | Writeup templates |
| `assets/` | Shared images |
